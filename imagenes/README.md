# Catálogo y Recursos Visuales (Imágenes) - Tenis-Arios

Este directorio contiene todos los activos visuales e imágenes organizados para el e-commerce de **Tenis-Arios**.

## Estructura de Directorios

```text
imagenes/
├── productos/    # Fotografías, renderizados y vistas multimedia de tenis y calzado.
└── marca/        # Logotipos, isotipos, banners publicitarios y recursos de marca.
```

## Guía de Formatos y Nombres

1. **Productos (`/productos`)**:
   - Formato recomendado: `.webp` o `.png` transparente.
   - Nomenclatura: `<marca>_<modelo>_<colorway>_<vista>.<ext>` (Ej: `nike_air_jordan_chicago_front.webp`).
2. **Marca (`/marca`)**:
   - Formato recomendado: `.svg` para vectores de logotipos y `.png` para banners alta resolución.
